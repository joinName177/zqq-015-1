# zqq-015 · 古文成语识别 · 片语考信

纯前端的古文段落成语识别与逐条考信工具。用户粘贴一段古文后，系统在原文上标出可能的成语片段，按三级置信度展示判定证据，支持逐条确认进入对比队列、对两条成语做字形/语义亲缘比对。**解析过程全程容错，任何解析失败都不会破坏当前原文与已有结果。**

## 功能

1. **粘贴即识别**：文本框粘贴古文（或载入《桃花源记》《岳阳楼记》《滕王阁序》《曹刿论战》示例），点击「开始识别」或 `Ctrl/⌘ + Enter`。
2. **原文标注**：在原文流上以三种颜色标出片段——黛蓝「辞书精确」、赭黄「异体近形」、紫灰虚框「结构疑似」；点击标注可滚动定位到对应候选卡片。
3. **置信度与证据**：每张候选卡片展示
   - 置信度（高 ≥80% / 中 ≥60% / 低 <60%）与进度条；
   - 规范词目、简释、典籍出处；
   - 命中处上下文（前后各 8 字）；
   - 可展开的「判定证据」（逐字相符、繁简异体归一、句读连读、结构特征等）。
4. **逐条确认入队**：每条候选可「确认入队 / 忽略 / 原文定位」，也可一键全部确认、一键忽略全部疑似；已确认条目汇入右侧对比队列（localStorage 持久化）。
5. **双词比对**：队列中各勾选一条（甲、乙），即时给出 0–100 亲缘分与「同源近义 / 近义相通 / 同域可参 / 形义迥别」分级，附用字重合、同字对位、共字、同书、义类交集与文字结论。
6. **容错与一致性**：
   - 解析在 `try/catch` 中执行，异常时保留原文与上次解析结果并提示，不清空任何内容；
   - 编辑原文后若未重新解析，标注区显示「结果为上一次解析」的脏状态提醒；
   - 生僻字、扩展 B/C/D 区汉字、超长文本、空输入、null/非字符串入参均不会导致崩溃；
   - 队列与原文自动存入 `localStorage`，存储损坏或不可用时静默降级。

## 识别原理

- **文字归一化**：NFKC + 内置繁简/异体/古今字对照表（仅用于匹配，不回改原文显示）。
- **清洗流对齐**：解析时跳过标点空白建立「净字流」，同时保留净字→原文下标映射，候选坐标始终映射回原始字符位置；候选跨度内部不允许夹句读，疑似窗口不跨句。
- **Trie 多模式匹配**：词目与其典籍异写（aliases）建前缀树，一次扫描得到全部命中；同词目重叠取最长书证，跨词目重叠按置信度→长度贪心消解。
- **三级判定**
  - `exact` 辞书精确（0.92–0.98）：归一化后与词目逐字相符；
  - `variant` 异体近形（0.86–0.90）：命中词目的典籍异写串；
  - `heuristic` 结构疑似（≤0.59）：4–6 字连续汉字块、四字格节奏、辞书二字组重合度、虚字密度、用字重复度等启发式信号，仅作提示，需人工确认。
- **比对算法**：用字重合（Jaccard 式）、同字对位比例、典籍同源、义类标签加权 Jaccard（单字需累计 2 分、二元词直命中），加权合成亲缘分。

## 架构（核心层 / 端口层 / 适配器层 / UI 层）

- `src/core/models.ts`：领域模型（`IdiomEntry`、`Candidate`、`AnalyzeResult`、`QueueItem`）与置信度分级。
- `src/core/extractor.ts`：归一化、Trie、重叠消解、结构疑似发现——纯函数式解析引擎。
- `src/core/compare.ts`：双词字形/语义比对算法。
- `src/ports/idiom-catalog.port.ts`：词库端口契约。
- `src/adapters/idiom-catalog.adapter.ts` + `idiom-catalog.data.ts`：内置约 590 条经史子集成语词库（含异体写法与出处）。
- `src/ui/`：原生 TS 渲染 + 宣纸墨韵 CSS（`app.ts` 视图/事件、`samples.ts` 示例、`styles.css`）。
- `src/main.ts`：状态编排、容错包装、localStorage 持久化。
